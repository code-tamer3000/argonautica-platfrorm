# Глифы стихий — контракт для отрисовки

Сюда кладутся нарисованные символы стихий. `glyphs.py` подхватывает их
автоматически, `render.py` подставляет в книгу. **Ничего в коде править не
нужно — только положить файлы с правильными именами.**

Если файла нет, книга собирается с запасным инлайновым символом (△ ▽ ◇ □), так
что можно нарисовать сначала одну стихию, прогнать рендер, посмотреть — и
дорисовать остальные.

## Имена файлов (ровно эти)

| Файл | Где стоит |
|---|---|
| `balance.png` | шмуцтитул главы «Точка баланса» |
| `air.png` | шмуцтитул главы «Воздух» |
| `fire.png` | шмуцтитул главы «Огонь» |
| `water.png` | шмуцтитул главы «Вода» |
| `earth.png` | шмуцтитул главы «Земля» |

Расширения: `.svg` (приоритет) → `.png` → `.webp` → `.jpg`.

Рисунок ставится **только на шмуцтитул**, размером ~40 мм. Мелкие места —
полоска символов на титуле (5 мм) и метки на карте пути (7 мм) — остаются
геометрическими: живой штрих на таком размере схлопывается в серое пятно.
Порог переключения — `MIN_DRAWN` в `templates/book.html.j2`.

## Требования к растру

- **1024×1024** и больше, квадрат. Точная центровка не нужна: скрипт обрезает
  по краске и сам выставляет одинаковые поля — оптический размер символов
  будет ровным сам собой.
- **Полярность любая, определяется автоматически** по краям кадра: белый глиф
  на чёрном (так отдаёт Nano Banana), чёрный на белом, или PNG с прозрачным
  фоном. Требование одно — фон ровный, без градиента и виньетки, иначе он
  просочится в краску.
- **Без собственного цвета, теней, свечения, рамок и подписей.** Цвет глифу
  задаёт книга: у каждой главы своя краска (воздух `#6e8299`, огонь `#b4472a`,
  вода `#2f6e7e`, земля `#6b7a46`, точка баланса `#8a6d46`), на титуле тот же
  символ печатается бледной линейкой `#cbbda6`. Цветной исходник эту палитру
  сломает.
- Штрих не тоньше ~6 px при 1024 — на 34 мм тонкая линия рассыпется.

## Что рисуем по смыслу

Классическая алхимическая система, книга сделана в духе рукописи:

- **Точка баланса** — круг с точкой в центре (не стихия, а исходная точка).
- **Воздух** — треугольник вершиной вверх с горизонтальной чертой.
- **Огонь** — треугольник вершиной вверх.
- **Вода** — треугольник вершиной вниз.
- **Земля** — треугольник вершиной вниз с горизонтальной чертой.

Пять символов должны читаться как **один набор**: одна толщина пера, один
нажим, одна степень небрежности. Разнобой заметнее всего на карте пути, где
все четыре стоят рядом.

## Заготовка промпта для Nano Banana

> A single alchemical element sigil: an upward triangle with a horizontal bar
> across it, wrapped in flowing wind curls. Hand-inked with a brush, slightly
> irregular stroke, visible texture and small imperfections, no perfect
> geometry. Pure white ink on a plain solid black background. Centered, no
> shadow, no glow, no frame, no lettering, no background texture, no color.
> Flat 2D, viewed straight on.

Меняй только первое предложение под символ (у каждой стихии свой характер
завитков: воздух — вихри, огонь — языки, вода — волны, земля — борозды),
остальное держи слово в слово — это и даёт единый набор. Генерируй все пять
**в одной сессии подряд**, тогда модель удерживает манеру.

Фон выйдет плотно-чёрным — это нормально, скрипт определит полярность сам.

## Растр → SVG (по желанию, не обязательно)

Для книги достаточно PNG: WeasyPrint встраивает его без потерь, а 1024 px на
34 мм — это ~760 dpi. Вектор нужен, только если захочется идеально резких
краёв.

Нейросеть для этого не нужна — векторизация это трейсинг, а не генерация:

```bash
inkscape fire.png --actions="select-all;trace-bitmap;delete;export-filename:fire.svg;export-plain-svg;export-do"
```

`potrace` (эталон для однотонных силуэтов) и `vtracer` в системе не стоят, но
ставятся одной командой. Онлайн — vectorizer.ai, SVGcode.

**Важно:** SVG кладётся в книгу как есть, без перекраски (перекрашивать чужую
вёрстку вслепую рискованно). То есть вектор потеряет посестихийную палитру —
все символы будут одного авторского цвета. Если палитра важна, оставайся на PNG.
